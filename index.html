01 / About

Calm systems, clear boundaries

I’m a backend engineer and team lead with 5+ years building and modernizing high-load systems, currently in fintech.

I’ve twice rebuilt legacy monoliths into event-driven microservices, and now lead the team integrating Finstar Financial Group’s platform solution into an international lending product. I stay hands-on: I write production services myself, run the infrastructure, and bring AI agents into how the team works.

The stack is C#/.NET and Go, with Kafka, Temporal, PostgreSQL, MongoDB and Redis on Kubernetes, and observability through OpenTelemetry. I use Domain-Driven Design, Clean Architecture and event-driven design so the boundaries stay clear as the system grows.

I take part in hiring and assessments, onboard and mentor new engineers, and I’m often the person colleagues ask for a second opinion on a design. I’m open to international roles that combine development with technical leadership.

  • 01

    Software design

    Rich domain models, DDD and Clean Architecture — boundaries that survive change.

    I proposed DDD and Clean Architecture for Finstar’s platform and set up the service project structure. At Cartis I co-designed the same move, splitting a stored-procedure monolith into 4 services, and presented the result to the CEO. I take part in ADR and system design discussions.

  • 02

    Backend & events

    .NET and Go microservices on Kafka — outbox for reliable delivery, Temporal for long-running workflows that span services.

    I write production services in C#/.NET and technical services in Go. I took part in Kafka and the outbox on Finstar’s loan platform, where each core service sustains 500+ RPS, and I delivered the Temporal integration for long-running processing. On the legacy LMS, RabbitMQ producers and consumers cut critical flows by up to 50%.

  • 03

    Data

    PostgreSQL, SQL Server, MongoDB, Redis and ClickHouse — safe, fast and tuned for real workloads.

    Core services persist to PostgreSQL and MongoDB, with Redis in front. On the legacy LMS I wrote SQL Server stored procedures and other database objects. At Cartis I designed the storage model, ran a zero-downtime ETL from MySQL into MongoDB, and moved application logs to ClickHouse.

  • 04

    Platform & observability

    A Kubernetes cluster running 30+ microservices, with Helm, CI/CD and OpenTelemetry — plus AI agents that shorten incident hunts.

    I look after cluster health and delivery, and the tracing, metrics and logs behind it: Jaeger, Prometheus and Graylog. I deployed MCP servers so internal agents can reach infrastructure and observability, which sped up bug localization, anomaly detection and QA.
